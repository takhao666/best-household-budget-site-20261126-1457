HomeLedger is a working household budget site for the Alvarez family: a dashboard with income vs spending, a transactions ledger you can add to, search and filter, budgets by category with live progress bars, savings goals, bills and recurring payments, and reports with spending-by-category and three-month trend charts. Every figure is real sample household data, every control works, edits save in localStorage, and the whole site is static files that run offline in a desktop browser and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
